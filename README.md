# آهنگ های تتلو ۲۰۲۶__۱۴۰۵

نسخه حرفه‌ای آماده انتقال به GitHub.

## قابلیت‌ها
- رابط کاربری RTL و تم آبی نئونی / مشکی / سرمه‌ای
- صفحه اصلی حرفه‌ای، جست‌وجو و کتابخانه آهنگ‌ها
- پخش‌کننده موسیقی
- صفحه جزئیات آهنگ
- پنل مدیریت
- ورود امن پنل با JWT و bcrypt
- مدیریت افزودن، ویرایش و حذف آهنگ
- آپلود کاور و فایل صوتی با محدودیت نوع/حجم
- rate limit و Helmet
- فشرده‌سازی
- SQLite
- robots.txt و sitemap.xml
- ساختار مناسب برای SEO
- تنظیمات محیطی با `.env`

## نکته
این آرشیو عمداً **بدون هیچ پوشه‌ای** ساخته شده و تمام فایل‌ها در ریشه ZIP قرار دارند.
